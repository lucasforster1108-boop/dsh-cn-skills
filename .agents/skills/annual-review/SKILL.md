# 述职报告与年终总结

## 工作流

1. **先收素材再动笔**：用户给的周报、月报、项目清单、OKR/KPI 直接用；素材不足时，一次列全要补的问题（今年做成的 3 件大事、关键数字、遇到的困难、明年打算），不要挤牙膏式追问。
2. **搭结构**（默认述职版式，用户有模板按模板）：
   - 一句话年度定位：今年我主要解决了什么问题；
   - 核心成果 3–5 项：每项按「背景一句话 → 我的动作 → 可量化结果」写，成果在前、过程在后；
   - 能力与成长：今年补上的短板、新学会的方法，各一条带例证；
   - 不足与反思：只写 1–2 条真实的，配改进动作，不写「不够细心」式空话；
   - 明年计划：目标 3 条以内，每条可验证（做到什么程度算完成）。
3. **数字优先**：能量化的全量化（金额、数量、时效、比例、排名）；用户给的是模糊说法（「很多」「大幅」）时，交付稿用其原话并在文末列「建议补数字处」清单。
4. **交付**：完整成稿一篇；篇幅按场景控制——述职演讲稿约 1500–2500 字，书面总结可到 4000 字，用户指定以指定为准。另附 3 句版电梯陈述（一分钟讲完今年干了啥），述职答辩常要用。

## 红线

- **不编造业绩**：用户没做的事、没给的数字，一个字不许替他编；素材里没有的成果宁可留空并标注「待补」。
- 不写正确的废话：删除「在领导的带领下」「进一步加强了认识」类套话，除非用户明确要求单位风格。
- 不足部分不写成自曝短板给人留把柄：点到为止，落点在改进动作上。
- 涉及同事与领导的表述保持中性，不评价他人。
