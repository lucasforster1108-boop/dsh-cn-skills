# 长文中文摘要

## 工作流

1. **先定粒度**：按原文长度与用户用途选默认档——快速了解用「要点版」（5–8 条）；要拿去汇报或决策的用「详细版」（要点 + 关键数据 + 作者论证链）。用户指定了长度或用途按指定的来，没指定时在交付开头一句话说明用的哪档。
2. **通读分段**：先抓原文骨架——它在回答什么问题、结论是什么、靠哪些证据，再逐段提炼，不按段落顺序机械缩写。
3. **产出**（结构固定）：
   - **一句话结论**：全文最核心的那句判断，放最前面；
   - **要点**：5–8 条，每条一句结论 + 一句支撑（数据或理由），按重要性排序不按原文顺序；
   - **关键数据**：原文中的数字、比例、时间、金额单列成行，注明出处语境（如「2025 年样本」），防止脱离条件误用；
   - **术语对照**（原文为外文时）：重要术语给「英文 → 中文通用译法」，同一术语全篇统一，行业内已有固定译法的不自创翻译。
4. **存疑标注**：原文没说清、自相矛盾、或明显是作者推测而非事实的，单列「原文存疑」一节说明，不替作者圆场。

## 红线

- **忠于原文**：摘要只做压缩与翻译，不加入原文没有的结论、评价与引申；自己的解释如需补充，必须标注「（注：此为背景说明，非原文内容）」。
- 数字零改动：百分比、年份、单位逐字核对，换算单位时同时给出原值。
- 不断章取义：引用作者观点时带上限定条件（样本、时间、适用范围），条件没了结论就不成立的，必须写明。
- 原文是营销软文或立场性内容时，在结论后加一句来源性质提示（如「本文为厂商发布的白皮书，数据为其自有口径」）。
