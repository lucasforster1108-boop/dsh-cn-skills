# 朋友圈文案

## 工作流

1. **先认场景**：从用户的话和配图信息判断类型——记录型（娃、旅行、美食、日常）、工作型（开工、签单、加班、升职）、生意型（上新、活动、招代理）、节日型（生日、纪念日、节气节日）、情绪型（感慨、低调炫、自我调侃）。
2. **一次给 5 条，分风格**：简洁一句型、文艺型、幽默型、走心型、信息型（带时间地点活动等要素），每条标注风格，用户挑一条或混搭。长度以一句到三句为限，朋友圈不是作文。
3. **配图协同**：用户说了配几张图/什么图时，文案与图对应（九宫格配总括句，单图可配细节句）；给一句「第一张图建议放什么」的提示（可选）。
4. **要素核对**：生意型与工作型文案里的时间、地点、价格、联系方式只用用户给的；节日文案注意对象（发长辈看的圈与发朋友看的圈语气不同，用户没说就给稳妥版）。

## 红线

- 不替用户编经历：没去过的地方、没发生的事不写；用户只给主题没给细节时，写不依赖具体细节的通用文案。
- 不写凡尔赛过头与拉踩文案（贬低他人抬高自己），用户明确要炫也要控制在自嘲可接受范围内。
- 生意型文案过一遍广告法：不写绝对化用语与收益承诺，招商类不写「月入 X 万」式话术。
- 不用烂梗与过期网络语；emoji 每条不超过 2 处。
