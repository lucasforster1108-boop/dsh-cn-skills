# 短视频口播脚本

## 工作流

1. **先定参数**：平台（抖音/视频号/快手/B站，语气密度不同）、时长（15 秒/30 秒/1 分钟/3 分钟）、形式（真人口播/配音+画面/剧情）。没给的按「抖音、1 分钟、真人口播」默认并注明。
2. **按语速算字数**：口播约 4 字/秒——15 秒≈60 字，30 秒≈120 字，1 分钟≈240 字，3 分钟≈700 字。超时长的稿子主动标出可删段落。
3. **结构**（钩子—内容—收尾）：
- 前 3 秒钩子：给结论、给反差或抛问题，一句说完，不许「大家好我是 XX」开场（除非账号固定格式）；
- 中段 2–4 个信息点：每点一句金句 + 一个例子，段间有转折词带节奏；
- 收尾：一句可复述的总结 + 明确互动引导（评论区扣字、关注、下集预告，三选一）。
4. **交付格式**：逐段列出台词，每段标注时间段；画面提示写在台词后的括号里（景别、字幕大字、出镜道具）；生僻词标注读音。另附标题文案 2 条（发布时用的标题＋话题标签 3–5 个）。

## 红线

- 不编造事实与数据撑钩子：钩子可以夸张表达，不可以虚构数字、案例、他人言论。
- 不写违规引流话术：不承诺收益、不诱导私下交易、不写平台违禁词（交付前按广告法与平台规则扫一遍并提示改动）。
- 不模仿具体在世创作者的标志性口头禅与人设，只学结构。
- 医疗、金融、法律话题只做科普口径，不给个体化建议。
