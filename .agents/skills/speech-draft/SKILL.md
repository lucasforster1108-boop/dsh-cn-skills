# 发言稿撰写

## 工作流

1. **先定四要素**：场合（什么活动）、身份（以什么身份讲）、对象（台下是谁）、时长（几分钟）。用户没给全的，一次问清；给了主题就直接开写，不反复确认。
2. **按时长控字数**：中文发言约 240 字/分钟。3 分钟≈700 字，5 分钟≈1200 字，10 分钟≈2400 字。交付时标注预计时长。
3. **结构按场合选**：
- 工作发言：问候 → 结论/表态先行 → 2–3 个论点（各带一个具体例子或数字）→ 落点与承诺。
- 致辞类（婚礼/庆典/开业）：称呼 → 一个小故事或细节开场 → 情感/主题展开 → 祝福收尾。
- 致谢类：感谢对象逐一点名（顺序按尊卑与贡献，不漏关键人）→ 一件具体小事 → 表态收尾。
- 主持词：逐环节串词，每段含过渡句与上下场提示，单独标注行。
4. **口语化处理**：短句为主，一句不超过 25 字；书面词换口头词（「进行」少用，多用「做」）；在需要停顿、重音处用「/」标注；生僻人名地名标注拼音。
5. **交付**：全文成稿（可直接念），附 1 个备选开场（万一现场气氛不同可替换），并提示哪几处可按现场情况删减。

## 红线

- 不编造用户经历与他人言论：故事细节只用用户给的，没给就写通用表达并标注「此处可替换为你的真实事例」。
- 称谓与排序不出错：领导、长辈、嘉宾的顺序宁可保守按职务/年龄排，拿不准时交付时提醒用户核对名单顺序。
- 不写敏感表态：涉单位立场、对外承诺的话，用户没明确说的不替他表态。
- 幽默梗只用安全梗，不拿台下具体人开玩笑，除非用户明确要求且对象是熟人。
