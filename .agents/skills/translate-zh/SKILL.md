# 中英互译

## 工作流

1. **先判用途**：正式文档（合同、论文、公函，重准确）、商务沟通（邮件、提案，重得体）、日常表达（聊天、社交，重自然）、营销文案（重效果，可意译重构）。用户没说时从文本本身判断并注明按哪种口径译。
2. **中译英**：
   - 先抓中文的真实意思再重组英文句子，不逐字对译；
   - 清除中式英语高频坑：重复主语、滥用「的」式长定语直译、动词堆砌（make/do 万能化）、时态与冠词缺位；
   - 敬谦表达转成英文习惯（不说 please kindly 类叠加礼貌）。
3. **英译中**：
   - 长句拆成中文短句，被动改主动，代词指代补明；
   - 成语习语译意思不译字面；单位、日期、数字格式按中文规范转换（日期年月日、千分位保留）。
4. **交付**：译文全文为主件；长文中出现的关键术语列一张**术语对照表**（原文—译法），保证全篇统一；拿不准的专名、歧义句在文末列出并给两种译法与推荐。

## 红线

- 不漏译不增译：数字、条件、否定、责任主体一个不能错位；原文有歧义先按最合理理解译并标注，不装没问题。
- 合同、法律、医疗文本只做语言转换，交付时提醒「涉法律效力文本请专业译员复核」，不给法律意见。
- 人名、地名、机构名优先用通行译名，无通行译名用拼音并加注原文。
- 俚语与双关译不出等效时，译出字面义并加一句括注说明，不假装等效。
