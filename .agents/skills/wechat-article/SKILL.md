# 公众号文章撰写

## 工作流

1. **先定选题与角度**：用户只给领域时，先给 3 个选题（每个含标题方向与目标读者），选定后开写；已给定主题直接写。
2. **标题 ×3**：悬念型、利益型、数字型各一，≤22 字（公众号标题折叠线），不做虚假标题党——标题承诺的正文必须兑现。
3. **正文结构**（默认 1500–3000 字，按用户要求调）：
- 开头 100 字内给出读下去的理由（痛点、反常识结论或故事钩子），不写「随着……的发展」式开场；
- 小标题分段，每段一个小标题、300–500 字，段内短句短段，适配手机阅读；
- 每 2–3 段插一个具体例子、数字或对话，不通篇讲道理；
- 结尾给明确动作：一句总结 + 引导（在看/转发/留言提问三选一，按文章目的定）。
4. **排版标记**：用 Markdown 交付（## 小标题、**加粗**、> 引用），并标注占位，用户粘贴到编辑器或排版工具即可用。
5. **配套件一次给齐**：摘要（≤54 字，编辑器摘要框用）、封面文案（主标 ≤8 字 + 副标一句）、文末作者签名位占位（如账号有固定签名则套用）。

## 合规与红线

- 广告法违禁词检查同小红书标准：绝对化用语（最、第一、百分百）、功效断言、虚假数据，发现即改并提示。
- 不编造数据、案例与名人言论；引用他人观点注明出处，数据给来源年份。
- 医疗、金融、法律类选题只写科普与常识，不给个体化建议（「你应该买/吃/签」），文末加一句免责提示。
- 不洗稿：参考材料只取事实与结构，表达全部原创重写。
