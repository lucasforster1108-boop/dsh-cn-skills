# 小红书笔记撰写

## 选题（用户没定主题时先走这步）

用户只给了领域、产品或账号定位时，先给 **5 个选题**，每个包含：题目一句话、切入角度、钩子类型（数字/痛点/身份/对比/避坑）、为什么值得写（搜索量大、痛点强、易收藏，三者占其一即可，说明占哪条）。选题排序按「易出收藏」优先——收藏率是小红书长尾流量的关键。用户选定一个后再进入下面的交付流程；用户已给主题则跳过这步。

## 交付物（一篇笔记给齐四件）

1. **标题 ×3**：从下面三种钩子里各出一个，让用户挑——
   - 数字型：「3 个方法 / 省了 2000 块 / 第 7 天」
   - 痛点型：「XX 之前没人告诉我的事」
   - 身份型：「干了 5 年 XX，说点真话」
   标题不超过 20 字，不用标题党虚假承诺（「看完立省十万」这类）。
2. **正文**：结构固定为——
   - 开头 2 行：痛点或结论先行（刷到的人 3 秒内决定去留）；
   - 干货分点：3–6 点，每点小标题 + 一两句说清，可复制照做；
   - 个人体验段：一两句真实感受或踩过的坑（没有用户提供的真实经历时，写成通用表述，不替用户编「我亲测」故事）；
   - 结尾互动：一句提问或「收藏下次用」，引导评论。
   全文口语化、短段落，一段不超过 3 行；emoji 点缀不超过 5 处，不堆符号。
3. **话题标签 5–8 个**：大词（流量）+ 长尾词（精准）搭配，如 #装修 #装修避坑 #卫生间防水 #自装日记。不加无关热词蹭流量。
4. **封面文案 ×3 组**：封面决定点击率，按三种打法各出一组——
   - 大字结论型：主标 ≤8 字直接给结论（如「防水别刷墙」），副标一句补条件；
   - 对比型：主标写前后反差（数字优先），副标点明方法；
   - 提问型：主标就是目标人群正在搜的问题，副标给答案预告。
   每组同时给一句**首图建议**（拍什么/截什么图、文字放上半区还是下半区、留白给标题的位置），用户选一组用。

## 合规检查（交付前必做）

- 广告法违禁词扫描：最、第一、顶级、绝对、百分百、国家级等绝对化用语，以及医疗/功效断言（治愈、根治、美白祛斑类功效承诺）——发现即替换为可证实的表述，并在交付时提示用户改了哪处。
- 不编造使用效果与对比数据；涉及价格、时长写用户给的真实数字，没给就不写具体数。
- 恰饭/推广类内容提醒用户标注，用户明确说不是推广则不啰嗦。

## 风格红线

- 不写 AI 味排比句（「不仅……更是……」连用）、不写「姐妹们冲」类与用户人设无关的硬套话；用户给了账号定位或过往笔记时，按其语气对齐。
- 正文不出现「作为 AI」类表述，产出就是终稿。
