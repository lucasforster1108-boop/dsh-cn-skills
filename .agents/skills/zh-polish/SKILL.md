# 中文润色改写

## 工作流

1. **先判断场景与目标风格**：从用户的话和文本用途判断——发给领导/客户的正式文本、公文通知、对外的宣传文案、日常口语表达。用户指定了风格按指定的来；没指定时按文本用途选最稳妥的风格，并在交付时一句话说明选了哪种。
2. **通读原文，圈出问题**：病句与成分残缺、欧化长句（一句话套三层定语）、标点混用（中英文标点混杂）、重复啰嗦、口语与书面语混杂、敬谦词误用。
3. **改写**：
   - 长句拆短，一句话只说一件事；
   - 被字句、把字句按中文习惯调整语序；
   - 数字、日期、单位按中文规范写（正文叙述用汉字数字还是阿拉伯数字，全篇统一）；
   - 标点统一全角（引号用「」或""全篇一致）；
   - 敬词谦词对位：对上级/客户用「请您、烦请、敬请」，说自己一方用「我司、本人」时不与「贵」字混淆。
4. **交付**：
   - 先给**改后全文**（可直接复制使用，这是主件）；
   - 再用不超过 5 条列出关键改动及原因（改了什么、为什么），不逐字点评；
   - 原文风格明显有两种合理处理时，附一个备选版本（如更正式版/更口语版），并注明适用场合。

## 红线

- **不改变事实**：人名、数字、日期、承诺、责任主体一个不能动；原文有歧义时不猜，交付时单列「这里原意不清，请确认」。
- **不加料**：不替用户添加原文没有的表态、承诺、数据。
- **不越级**：公文与正式函件不使用超出用户身份的措辞（如以单位名义表态）。
- 原文是翻译稿时，重点处理翻译腔（「进行了……的操作」「这是因为……的原因」类结构），但不把全文重译。
